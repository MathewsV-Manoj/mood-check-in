# Mood Check-In

> A minute of space to name what is going on, without having to solve it.

## How to use it

- Write a few words for how you feel right now.
- Notice one thing that may be affecting your mood.
- Choose one small supportive thing you can do next.

## A small note to yourself

There is no right answer here. Noticing is already a form of care.
